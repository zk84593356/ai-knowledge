# 内容工作台说明

这个文件夹是你的内容工作台，由 ai-knowledge Skill 初始化生成。以后的选题、资料、稿件、风格和品牌都放在这里。里面的文件都是你的，可以随意修改；重装或更新 Skill 不会覆盖这里的任何东西。

## 目录

```text
内容工作台/
  工作台说明.md          本文件
  用户人设.md            你是谁、写给谁、什么口吻（默认人设，建议改成你自己的）
  风格参考/              你喜欢的文章和它们的写法拆解；AI 学到的你的写作规则
    如何用 Grok Bot 做内容.md   外部范例的写法拆解
    我的写作规则.md      确认过的个人写作习惯
    我的写作档案.md      你的整体风格描述
    改稿学习日志.md      每次风格学习的记录
  写作技巧/              写作方法，AI 写稿时按这里的版本来
    内容写作技巧.md
    金字塔原理写作技巧.md
    偏航句用法.md
  规范指南/              平台规则和运营方法
    自媒体防限流指南.md
    口播引导话术.md
    自媒体动画.md
    运营沉淀.md
  品牌资产/              视觉品牌，每个品牌一个文件夹（可选）
  我的项目/              写作过程中沉淀下来的东西
    _briefs/             每篇文章的需求卡
    _knowledge_base/     调研资料卡，同主题下次直接复用
    _协作文档/           需要你实测、截图或补经历时的任务单
    公众号写作/          主稿：<日期>-<主题>/article.md、review.md、assets/
    推文写作/            小红书、微博、X 的改编稿
    短视频逐字稿/        口播稿
    历史存档/            发布后的稿件
```

## 三步开始

1. **初始化工作台**（已完成）。
2. **建品牌资产**（可选）。不建也能写，配图用通用图解风格。要建的话看 [品牌资产说明](品牌资产/品牌资产说明.md)。
3. **开始写**。在你的 Agent 工具里说：

```text
$ai-knowledge 写一篇讲清 OAuth 和 OIDC 区别的文章，读者是刚接触统一登录的后端。
```

AI 会按需求卡 → 调研 → 选角度（等你确认）→ 写初稿 → 打磨 → 配图 → 交付的顺序来做，稿件放进 `我的项目/公众号写作/`。

## 谁维护什么

| 内容 | 谁来改 | 说明 |
| --- | --- | --- |
| 用户人设.md | 你 | AI 只读，不会替你补身份和经历 |
| 写作技巧/、规范指南/ | 你 | 初始化时是 Skill 自带的版本；你改了以后，AI 按你改的来 |
| 风格参考/ 里的范例 | 你 | 放你喜欢的文章或拆解，AI 只学方法 |
| 我的写作规则.md 等 | AI 起草，你确认 | 复盘改稿后 AI 记候选规则，你确认后才生效 |
| 品牌资产/ | AI 起草，你确认 | 草稿品牌只在你点名时使用 |
| 我的项目/ | AI 写，你审 | 只有你说"可以发布"，稿件状态才会改为可发布 |

不管你怎么改这些文件，有几条底线不会变：不编造经历和数据，事实有依据，不泄露隐私，不替你发布。

## 备份

整个文件夹可以放进私有 Git 仓库或网盘同步。不要放进公开仓库：用户人设、改稿记录和品牌素材都是你的私人资料。
