# 改稿学习日志

这里记录每一次风格学习做了什么：对比了哪两个版本、发现了什么、哪些规则被新增、修改或撤回，以及依据是什么。它让你随时能查到某条规则是怎么来的。

只记必要的变化和原因。私人原文、客户信息和未公开的内容不存在这里，只写类别和位置。同一个版本重复复盘、没有新变化时，不追加记录。

## 记录格式

```markdown
## LEARN-20261017-01

- 日期：2026-10-17
- 类型：改稿复盘 / 风格分析 / 手动导入
- 来源：我的项目/历史存档/公众号写作/20261017-oidc-callback（AI 交付稿与作者终稿）
- 变化：新增候选 MY-001；MY-000 支持次数 +1
- 你的确认：无（候选）/ 2026-10-18 回复"这条可以"
- 不纳入：哪些观察没有记成规则，为什么
```
