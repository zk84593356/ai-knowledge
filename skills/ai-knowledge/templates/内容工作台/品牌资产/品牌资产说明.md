# 品牌资产

这里放你的视觉品牌。每个品牌一个文件夹，文件夹名就是品牌 ID，例如 `品牌资产/my-brand/`。可以放多个品牌，写文章时 AI 会问你这次用哪一个。

不建品牌也完全可以：配图会用 Skill 自带的通用图解风格。

## 一个品牌文件夹里有什么

```text
品牌资产/<品牌ID>/
  brand-kit.json     品牌清单：名字、状态、配色、登记过的图片
  character.md       角色规范：不能变的识别点、生图提示词、验收清单
  style.md           风格规范：配色、视觉语言、各类图的做法
  provenance.md      来源与授权：原图从哪来、能不能公开
  assets/
    canonical/       角色母版：原图、三视图、细节图
    scenes/          场景图
    samples/         风格样板（只做风格参考）
  candidates/        生成后还没选中的候选图，不登记、不使用
```

## 怎么建一个品牌

**方法一：让 AI 帮你建。** 在你的 Agent 工具里发一张人物或角色图，说：

```text
$ai-knowledge 用这张图建立一个视觉品牌，品牌 ID 叫 my-brand，名字叫"我的品牌"。
```

AI 会在这里建好 `my-brand/` 文件夹，把原图存为母版，起草角色规范和风格规范，等你确认后把状态改为正式。

**方法二：复制以前做好的品牌。** 把整个品牌文件夹复制到这里即可，文件夹名要和 `brand-kit.json` 里的 `brandId` 一致。复制后可以让 AI 检查一遍：

```text
$ai-knowledge 检查一下 品牌资产/my-brand 能不能用。
```

## 品牌 ID 的规则

只用小写英文字母、数字和连字符，最长 40 个字符，例如 `my-brand`、`tech-cat`。显示名可以是中文，写在 `brand-kit.json` 的 `name` 里。

## 草稿和正式

- **草稿**（`draft`）：刚建好、还没确认。只有你在请求里点名这个品牌时才会用。
- **正式**（`confirmed`）：你确认过角色和风格。写文章时 AI 会把正式品牌列出来让你选。

## 注意

品牌素材默认只在你本机使用。整个工作台放进私有仓库备份没问题，但不要把 `品牌资产/` 放进公开仓库，除非 `provenance.md` 里写明可以公开。
