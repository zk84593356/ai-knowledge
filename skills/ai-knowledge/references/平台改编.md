# 平台改编：同一个判断，换一种读法

第 9 步用，作者要求时才做。改编不是把长文缩短，而是按平台的阅读方式重新组织：读者在哪看、看多久、靠什么决定继续看。主稿 article.md 不动。

## 共同规则

- **事实不变**：改编稿里的每个事实都来自主稿和它的证据表，不新增主稿没有的结论、数据和经历。需要新内容时先补进主稿和证据表。
- **核心判断不变**：平台不同，开头可以换，结论不能换。
- **再查一遍规则**：标题、互动引导、导流、AI 标识按 [防限流指南](自媒体防限流指南.md) 对照目标平台检查。
- **只放可发布的内容**：改编稿里只写要发出去的文字和画面说明；做了哪些检查、还缺什么，写进主稿 review.md 的“发布状态”。

## 放在哪里

| 工作台 | 位置 |
| --- | --- |
| 有内容工作台 | 图文短帖放 `我的项目/推文写作/<YYYYMMDD>-<topic-slug>/`，文件名 `xiaohongshu.md`、`weibo.md`、`x.md`；口播稿放 `我的项目/短视频逐字稿/<YYYYMMDD>-<topic-slug>/口播稿.md` |
| 没有工作台 | 与主稿同目录，文件名同上 |

日期和 slug 与主稿目录一致，方便对应。

## 各平台怎么改

下表的字数和尺寸是写作时的常见值，平台会调整；发布前以平台当前规定为准。

| 平台 | 读者怎么看 | 改编要点 |
| --- | --- | --- |
| 公众号 / 知乎 / 掘金 | 点进来读长文 | 直接用 article.md。公众号标题常见上限 64 字，摘要栏常见上限 120 字 |
| X 长文 | 同上 | 直接用 article.md；英文读者另写，不机翻 |
| 小红书 | 先看封面和标题，再左右滑图 | 3–9 张竖版图（常用 3:4），每张一个要点，图片承担主要信息；标题常见上限 20 字；正文常见上限 1000 字，讲清“为什么值得看”和关键结论 |
| 微博 | 信息流里扫一眼 | 一条只放一个最有冲击力的结论和一张图，需要时引向长文 |
| X 短帖 | 信息流里扫一眼 | 普通账号单条 280 字符（中文字计 2）；可拆成串，首条独立成立 |
| 短视频口播 | 前几秒决定是否划走 | 见下一节 |

### 小红书

- 第 1 张图是封面：大字写核心判断或读者的问题，人物或主体清楚。
- 第 2 到倒数第 2 张：每张一个要点，图上的字一眼能读完。
- 最后一张：总结或清单，适合收藏。
- 正文第一句重复封面的钩子，然后用短段落讲清结论；话题标签放文末，2–5 个，与内容相关。
- 不在图片、正文、评论里留站外联系方式。

### 微博和 X

- 首句就是结论，不铺垫。
- 一条只讲一件事。要讲几件事，就写成串，每条开头编号。
- 配图选主稿里信息最密的那张，不配纯装饰图。

### 短视频口播

用 [口播稿模板](../templates/口播稿-template.md)，写进 `口播稿.md`：

1. **定时长**：先定目标时长，再按每分钟约 230 字估算字数。百度百科“语速”词条引用的统计是，汉语新闻播音常规语速为每分钟 240–350 个音节；口播常用的每分钟 200–260 字是经验值，没有权威出处，按作者实际语速调整。
2. **只讲一个核心判断**：长文里的多个要点挑最重要的 2–3 个，其余放弃或引向长文。
3. **写成口语**：短句，少用书面连词；数字和术语放慢说，必要时上字幕；避免读起来拗口的长定语。
4. **分镜对齐**：每段口播旁写清画面、字幕和动效，动效按 [自媒体动画](自媒体动画.md) 设计。
5. **开头和结尾**：开头钩子、中段提示、结尾引导按 [口播引导话术](口播引导话术.md)。
6. **读一遍计时**：写完让作者或朗读工具读一遍，按实际时长删改。

### 封面尺寸

主稿封面默认 16:9（例如 1600×900），标题放在垂直方向中间约 75% 的安全带内，裁成公众号的 2.35:1 横图时文字不被切掉。小红书竖版图（3:4，例如 1242×1656）、视频封面等单独导出，不拉伸。配图制作见 [配图与资产验收](视觉-配图验收.md)。
