# 自媒体动画：让画面跟着口播走

写口播稿的“画面”和“动效”两列时用。本 Skill 不直接做视频，只把每段口播需要什么画面、什么动效写清楚，交给作者或剪辑工具执行。

## 常用的动画类型

| 类型 | 适合表达 | 例子 |
| --- | --- | --- |
| 关键词文字动效 | 结论、术语、数字 | 口播说到“三个随机值”，三个词依次弹出 |
| 图解逐步出现 | 流程、结构、因果链 | 登录流程图一步一步亮起 |
| 数据对比动画 | 前后对比、多方对比 | 柱状图从零长到实测数值 |
| 屏幕录制推近与高亮 | 操作步骤、代码、界面 | 录屏放大到报错那一行，加框 |
| 示意或角色动画 | 抽象概念、类比 | 品牌角色指向关键位置 |
| 转场 | 段落切换 | 从第一点切到第二点 |

## 节奏原则

这些是制作经验，不是平台规则：

- **对齐口播**：动效出现的时刻和口播里的关键词对齐，差几帧观众就会觉得不同步。写稿时在口播文字里标出触发词。
- **一个动效一个信息点**：同一时刻不让两处同时动。
- **转场服务段落**：只在换要点时用转场，不是每个镜头都切。
- **不挡字**：字幕和动效不互相遮挡，手机竖屏下字幕区域留空。
- **数据画面必须准**：柱长、比例、坐标轴按真实数值画，数字来自证据表。

## 工具怎么选

只列能查证的能力；版本和价格变化快，用前看官网。

| 工具 | 能做什么 | 适合 |
| --- | --- | --- |
| 剪映 | 关键帧动画（位置、缩放、不透明度等），软件自动补齐两帧之间的变化；提供 AI 生成和剪辑功能 | 口播类快速出片、文字动效 |
| Canva | 对页面或元素应用动画 | 模板化图文、简单动效 |
| After Effects | 专业动态图形与合成 | 复杂动效，需要专业剪辑能力 |
| Manim（社区版） | 用 Python 写数学动画 | 公式、几何、推导过程 |
| Motion Canvas | 用 TypeScript 写信息类矢量动画，带实时预览 | 流程图、代码讲解动画 |
| Remotion | 用 React 写代码生成视频，可批量渲染 | 系列化、数据驱动的视频；公司使用需遵守其许可条款 |
| 可灵、即梦、Runway 等 AI 视频工具 | 文生视频、图生视频 | 空镜、氛围画面、示意画面 |

AI 视频工具不适合需要精确数据或精确文字的画面，生成的人物和场景也不能当成真实记录。用它们生成的内容，按 [防限流指南](自媒体防限流指南.md) 的 AI 标识要求主动声明。

## 写进口播稿

在 [口播稿模板](../templates/口播稿-template.md) 的每一行写：

- **画面**：观众看到什么，素材从哪来（主稿配图、录屏、实拍、AI 生成）。
- **动效**：类型、触发词、持续时间。
- **字幕**：需要额外强调的字，通常是数字和术语。

素材使用主稿 `assets/` 里已登记的图片时写文件名；需要新做的素材列为待制作项，不在稿子里假装已经有。
